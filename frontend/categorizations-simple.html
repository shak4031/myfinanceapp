✅ How Categorization Works

Your transactions are automatically categorized based on:

  • Auto-Detection: Patterns from merchant names and descriptions
  • Smart Learning: Categories you've manually set before
  • Historical Data: Transaction history and known merchants

📊 Review Your Categorizations

To review and modify how transactions are categorized:

Go to Dashboard → Categories Tab

This page shows all your transactions grouped by category with ability to:

  • View by Category: See all spending in each category
  • Drill Down by Month: Click a month to see individual transactions
  • Verify Categorization: Confirm transactions are in the right category
  • See Trends: Track spending patterns over time

🔧 Need to Fix a Categorization?

If you notice a transaction is categorized incorrectly:

  1. Dashboard → Categories: Find the transaction in the category month view
  2. Note the Description: Remember the merchant/description name
  3. Future Imports: System will remember this correction for similar transactions

💡 Pro Tips

• Categories are smart: Correcting one transaction teaches the system about similar ones
• Monthly View: Use the Categories tab's month filter to review specific periods
• Search & Filter: Use dashboard features to find specific merchants
• Consistent Tagging: Regular review helps improve auto-categorization accuracy
